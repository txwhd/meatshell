# 移植参考目录的 MFA 功能

来源为 `D:/github/meatshell-main` 的 0.8.2 定制版；目标为当前分支的
0.8.3。将连续 MFA、共享 SFTP 和 TOTP 管理移植到当前代码。

| 场景 | 预期 |
|---|---|
| A1 密码、私钥或 Agent 首因素后要求验证码 | 在同一连接继续交互认证，只接受最终成功 |
| A2 错误验证码、取消、服务端断开、多轮挑战 | 不误登录；取消/断开可结束等待；最多 16 轮 |
| A3 已认证终端启动文件面板、传输和 sudo | 同连接新 channel，不再次 MFA；SFTP 失败不关闭终端 |
| A4 新增/编辑/删除 TOTP，SSH 会话引用 | 支持 Base32/otpauth、动态码和倒计时；删除清除引用 |
| A5 自动验证码与人工输入 | 仅绑定会话的明确隐藏 OTP 字段自动应答一次；其余人工输入 |
| A6 密钥存储与导入导出 | 本机密钥加密；无法解密的密文保留；导出无密钥和本机引用 |
| A7 不变：普通认证、共享凭据和当前终端/SFTP 功能 | 保留 0.8.3 行为及 russh 0.61 系列依赖 |

后续按用户要求完成 Windows 本机部署，并执行本地 Git 提交；不执行推送
或正式发布。自动化不访问真实服务器或用户 MFA 密钥。
